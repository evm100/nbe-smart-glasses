# Week 1 Smart Glasses Experiments
## 60 minutes

### Goals this week:
- Proof of concept of PPG -> BP pipeline
- Not aiming for generalization
- Not aiming to filter glasses sensor shifting on skin
- Recording PPGs {glasses, fixed on head (headband/taped), finger}
- Cuff on left arm, finger on right hand
- Correlation between PPG and BP
- 100 BP points

---

| Time | Action |
| ---- | ---- |
| 10 min | Setup, signal check |
| 5 min | Seated rest, cuff x3 |
| 3 min | Silent mental arithmetic |
| 3 min | recovery |
| 2 min | wall sit |
| 4 min | recovery |
| 2 min | cold pressor, foot in ice water |
| 5 min | recovery |
| 3 min | squats or stationary low motion exercise |
| 8 min | seated recovery |
| 3 min | head movements for sensor shifting reference |
| 3 min | final rest |

#### Notes:
- silent actions prevent glasses from moving around
- foot used to not affect fingers/arms
- 8 min post-exercise gives biggest SBP range
- cuff readings every 1-2 min, operator marks moment inflation starts
- cold pressor 'tends to raise BP with relatively little HR change'
- Keep head/heart geometry fixed
